BenchLM Mirror

«Автоматически обновляемое зеркало публичных данных BenchLM.»

🎯 Зачем это?

Этот репозиторий создан для удобного доступа к данным BenchLM из сторонних приложений и проектов.

Здесь вы можете:

- 📥 Получать актуальные данные — файлы автоматически обновляются раз в день.
- 🕐 Просматривать историю изменений — благодаря Git можно посмотреть предыдущие версии данных и отследить их изменения во времени.
- 🔗 Использовать данные в своих проектах — JSON-файлы доступны напрямую через GitHub Raw и могут использоваться как простой источник данных.
- 🚀 Создавать запросы напрямую к GitHub — отдельный сервер или API для получения этих данных не требуется. Частота запросов ограничивается лимитами GitHub.

Таким образом, репозиторий может использоваться как простой промежуточный источник данных BenchLM для сайтов, приложений, ботов, аналитических инструментов и других проектов.

📊 Данные

Файл| Описание
""models.json"" (./data/models.json)| Информация об ИИ-моделях
""leaderboard.json"" (./data/leaderboard.json)| Рейтинг моделей
""benchmarks.json"" (./data/benchmarks.json)| Информация о бенчмарках
""pricing.json"" (./data/pricing.json)| Цены на модели
""speed.json"" (./data/speed.json)| Скорость и производительность моделей
""comparisons.json"" (./data/comparisons.json)| Сравнения моделей

Все данные находятся в директории ""data/"" (./data).

🔄 Автоматическое обновление

Данные автоматически загружаются с BenchLM раз в день с помощью GitHub Actions.

При каждом обновлении:

1. Загружаются последние данные.
2. Файлы сохраняются в "data/".
3. Проверяются изменения.
4. Если данные изменились, создаётся новый commit.

Обновление также можно запустить вручную через вкладку Actions.

🔗 Использование

Например, "models.json" можно получить напрямую:

https://raw.githubusercontent.com/seregannj/benchlmirror/main/data/models.json

Другие файлы доступны по аналогичному адресу.

🔗 Источник

Источник данных: "BenchLM" (https://benchlm.ai/data)

Этот репозиторий является независимым зеркалом и не связан с BenchLM напрямую.

⚖️ Примечание

Зеркалируемые данные принадлежат их первоначальному источнику.

Перед использованием данных ознакомьтесь с условиями и требованиями BenchLM.
